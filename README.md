# Vendix

Sistema de Frente de Caixa (PDV) para supermercados — projeto de preparação
para a Imersão Exponencial 2026.

Stack: Laravel + Vue 3 (Inertia) + MySQL, ambiente via Laravel Sail.

Veja o design completo em
[`docs/superpowers/specs/2026-10-15-vendix-pdv-design.md`](docs/superpowers/specs/2026-10-15-vendix-pdv-design.md)
e as instruções para agentes de IA em [`AGENTS.md`](AGENTS.md).

## Status

Projeto ainda não iniciado — spec aprovada, próximo passo é gerar o plano de
implementação.
